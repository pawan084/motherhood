Aira — redesign proposal (Dawn)

Each screen twice: as built (left, mirrors the shipping Compose UI — canonical reference in index.html) and proposed (right). The proposal is driven by two CSS blocks at the top of this file: the .v2{…} token block (recolours) and the .v2 … overrides (reshapes). Edit those two blocks and every proposed phone updates at once — no markup changes needed to try a different direction.

The six moves

  1. Twilight → Dawn. The dark plum hero becomes a light sunrise gradient (peach → lilac) with plum ink — calmer in daylight, less "night mode by default".
  2. Shadows replace borders. Cards, bubbles, and tiles drop their 1px outlines for soft plum-tinted shadows and larger radii — a softer, more tactile surface.
  3. A warm second accent. Rose (--rose) joins plum: eyebrows, tool tiles, and category chips warm up; sage stays for "done/safe".
  4. Frosted nav. The dark floating pill becomes frosted white with a solid plum active tab — content glows through instead of being anchored by a dark bar.
  5. Editorial serif. Fraunces gains italics for greetings and emphasis words; the welcome headline grows. The voice reads more like a companion, less like a system.
  6. Rounder controls. Buttons, options, segments, mood chips and check buttons go full-pill/circle; the primary button gets a subtle plum gradient.
